# 饥荒战斗训练

在线练习：https://zhaoziyu663-byte.github.io/starve_chaos-training_pot/

推送到 `main` 后，GitHub Actions 自动测试并将 `dist/` 发布到 GitHub Pages。

独立网页训练器，基于本机 Don't Starve Together 762172 的公开 Lua 脚本和原版素材制作。游戏安装目录仅用于只读提取，网页运行时完全不访问游戏文件。

## 运行

双击 `启动训练器.cmd`，或在此目录运行 `npm start` 后访问 http://127.0.0.1:4173 。需要本机 Node.js。关闭运行窗口可停止本地服务器。

## 当前版本

- 共 29 种，每轮同类 1–12 只。保留普通蜘蛛、普通猎犬、高脚鸟、普通体型树精守卫、触手、杀人蜂、普通发条骑士、疯猪。
- 新增 20 种：猪人、猪人守卫、兔人、鱼人、鱼人守卫、皮弗娄牛、夏象、冬象、蜘蛛战士、洞穴蜘蛛、垂悬蜘蛛、蝙蝠、青蛙、蜜蜂、蚊子、企鸥、浣猫、坎普斯、伏特羊、蜗牛；另加入普通独眼巨鹿。
- 固定女武神：200 生命、1.25 武器伤害倍率、25% 减伤和基础战斗回血。
- 15 格原版样式物品栏与手部装备位。初始手持第一把矛；默认 1/2 为矛与步行手杖、1/3 为两把矛、4 为未充能奔雷矛，第 15 格为无限干草。按数字 1–0 或右键格子装备；左键拿起、放入或交换，支持拖动换格；左键手部格可卸下，右键手部格放回背包。头部和身体格仅展示空位。
- 矛、步行手杖、未充能奔雷矛均可逐件调整基础攻击力；攻速不可调整。手杖移速 7.5，普通移速 6。切换武器会取消攻击动作：命中前切换取消本次伤害，命中后可取消后摇，但保留原版 0.4 秒共享攻击冷却，避免模拟出无间隔连击。
- 奔雷矛默认解锁一级加强技能：右键出现原版金色方向箭头，移动鼠标调整，再按左键冲刺；右键或 Esc 取消瞄准。原版 12 帧准备、沿路径攻击后位移 6.5 单位、17 帧恢复、3 秒冷却；首次装备也有 3 秒冷却。技能基础伤害固定 68，不随普通攻击力输入变化。没有无敌帧；准备中仍受伤，恢复可被打断。
- 奔雷矛在物品格与装备格中显示原版蓝色充能覆盖和就绪闪光。冷却绑定物品，即使拿到鼠标上、放回背包或掉在地上也继续计时；已就绪的矛重新装备会重新进入 3 秒冷却。
- WASD 移动，F 持续攻击；点击怪物选择并攻击，点击地面移动。空格拾取附近掉落物，也可点击地上的物品；鼠标拿着物品时点击地面丢下。Esc 优先取消瞄准/放回鼠标物品，否则暂停；R 重开并保留物品排列。
- 按用户指定的练习规则，青蛙命中只打落干草，不掉其他物品。干草显示 ∞，供给不减少；可移动格子、丢下和拾取，但不能装备或修改伤害。地面草最多保留 32 堆，避免长时间练习持续增加对象；这是训练便利规则，不代表原版无限供给。
- 攻击范围黑色虚线，攻击状态变红。真实命中按当前距离、目标半径和原版时间轴计算。
- 玩家与怪物头顶血量；树精和巨鹿显示原 Epic Healthbar 边框，并按当前目标切换。
- 原版动画、武器、地面、HUD、冲刺及命中电光。草地环境、非战斗工作音乐、普通战斗音乐、Boss 战斗音乐按状态切换。首次点击开始或声音按钮解锁音频；切出页面自动暂停。
- 怪物素材按选择加载，首载只载入 9 个公共模型；相同图集复用，保留有容量上限的合成帧缓存。

## 校核与范围

战斗模拟固定 30 步/秒，与显示刷新率解耦。核心时间轴来自安装版 `scripts.zip` 中的 `SGwilson.lua`、`SGspider.lua`、`SGhound.lua`、`SGtallbird.lua`、`SGLeif.lua`、`SGtentacle.lua`、`tuning.lua`、`combat.lua` 及相关 AI。

验证命令：

```
node tools/test-combat.mjs
node tools/test-audio.mjs
node tools/test-range.mjs
node tools/test-render.mjs
node tools/test-skills.mjs
node tools/test-inventory.mjs
node tools/test-extra-monsters.mjs
node tools/test-ground-items.mjs
node tools/test-deerclops.mjs
```

未包括其余技能树、战歌、奔雷矛充能、击杀灵魂收益、装备护甲、环境生存与联机预测。开放场地中的寻路和身体碰撞是独立近似实现。音乐与声音使用原始样本，未移植完整 FMOD 混音/DSP 图。尚未进行与原游戏联机实机的逐帧手感对照。

独眼巨鹿按本地当前版本实现：4000 生命、75 基础对玩家伤害、4 秒攻击间隔，起手前 16 帧跟踪朝向，其后锁定方向；第 31 帧产生原版冰刺，按每根冰刺的位置与延迟命中，最早第 34 帧生效；同一次攻击不会因多根冰刺重复伤害。包含玩家冷冻累积、冻结、解冻与受击破冰；怪物间的冰刺伤害支持，但怪物冻结未完整模拟。未加入圣诞巨鹿、建筑破坏及季节生成系统。

触手已按原版SGtentacle校正：定时索敌与保留目标半径、地下翻动、带距离条件的出土、攻击循环第7/17帧命中、第18帧后可受击打断，受击结束直接接攻击；丢失目标后按动作收回。地下被打不凭空创建仇恨。八种怪物均接入相应电击状态，包含触手地下免电击、骑士触电后倒地恢复及树精电击抵抗。

2026-11-11 距离复核：按玩家自己创建世界的主机规则，普通矛和未充能奔雷矛的攻击起手/命中为中心距 ≤ 2 + 目标物理半径。普通蜘蛛、猎犬、高脚鸟、中型树精半径0.5，阈值2.5；触手半径0.25，阈值2.25。客户端额外向内0.5的预测补偿不应用于主机规则。命中时重新检查距离，贴图中的矛尖并非碰撞检测对象。

显示比例改用150源动画像素/世界单位，普通体型统一Transform比例1，修复首版分别缩小怪物造成的距离错觉。比例依据本地 `prefabs/offering_pot.lua:39`、`storage_robot.lua:31` 中的源图尺寸/150换算；网页镜头仍是独立正交近似，并非实机像素级标定。地面纹理/阴影预合成，角色动画缓存合成帧；战斗及原动画仍按30帧时间轴执行。
